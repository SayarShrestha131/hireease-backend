Review Actions

Approve KYC Submission

This will approve the user's KYC and allow them to book vehicles.

Reject KYC Submission

This will reject the submission. User will NOT be able to book vehicles.

User will see this message. Be clear and professional.

Request KYC Resubmission

This will reject the current submission and ask the user to resubmit with corrections.

Be specific about what needs to be fixed. User will see this message.
